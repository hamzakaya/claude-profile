# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep criticism about the code, not the person. Harassment, insults and personal attacks aren't tolerated in issues, pull requests or anywhere else the project lives.

Report unacceptable behavior to **hamza@hamzakaya.net**. Reports are handled confidentially. The maintainer may remove comments, lock threads or ban accounts that break these rules.
